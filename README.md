# Aqtar Shaik — Performance Engineering Portfolio

This is a static, GitHub Pages-ready portfolio website.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `aqtar-performance-portfolio`.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will provide the public portfolio URL.

## Customize

- Update the LinkedIn URL if needed.
- Add a profile photo or project screenshots if desired.
- Add links to public GitHub repositories or performance reports only when they are safe to share.
- Do not publish confidential employer data, credentials, internal URLs, API keys, customer information or proprietary test results.
